# Mapa Eleitoral 2026

Ferramenta de análise da eleição presidencial de 2026 (1º e 2º turno) por estado e município, cruzada com IDHM, Ideb, saneamento (Censo 2022) e IPS Brasil 2026.

- Arquivo único: `public/index.html` (dados, mapa e bibliotecas embutidos; funciona sem internet, exceto as fontes do Google, que têm fonte reserva).
- Fontes: TSE (Dados Abertos), Atlas Brasil, Inep, IBGE/SIDRA e IPS Brasil.

## Atualizar

Substitua `public/index.html` pela nova versão e faça commit. A Cloudflare publica sozinha a cada commit na branch `main`.
